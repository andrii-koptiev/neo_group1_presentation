# TEAM_OS — Neoversity

Інтерактивна презентація команди українською. React, TypeScript, Vite, Framer Motion, звичайний CSS. Без бекенду, авторизації та API. Шрифти постачаються локально з npm, тому після запуску інтернет для показу не потрібен.

## Запуск

```sh
npm install
npm run dev
```

Відкрийте **http://localhost:4287**. Порт 5173 не використовується. `strictPort` не дозволяє непомітно перейти на інший порт. Preview використовує 4288.

```sh
npm run build
npm run preview
```

## Керування

- `→` / `Space`: наступний слайд / учасник.
- `←`: попередній слайд.
- `Escape`: повернутися до команди з профілю.
- `Home` / `End`: вступ / фінал.
- Картка учасника відкриває його профіль. Усі сім відповідей видно одночасно; стрілки перемикають учасників.
- Кнопка у правому верхньому куті вмикає повноекранний режим, якщо браузер підтримує його.
- Space на кнопці використовує стандартну активацію кнопки без подвійного переходу.

## Заміна даних

У **src/data/team.ts**:

1. Редагуйте об’єкти масиву `team` або додавайте нових учасників. Кожен має унікальний `id` та всі поля `TeamMember`.
2. Додавайте до 11 об’єктів без змін компонентів — порядок слайдів, кількість учасників і прогрес перебудовуються автоматично.
3. Додайте фото до `public/photos/` та вкажіть `image: 'photos/andrii.jpg'`, `imageAlt: 'Портрет Андрія'`. Без фото або якщо файл недоступний, відобразиться аватар-заглушка.
   Для портрета з прозорим фоном додайте `imageStyle: 'cutout'`: портрет відобразиться без рамки в профілі та без обрізання обличчя. Щоб фото швидко завантажувалось на GitHub Pages, збережіть оригінал як `<id>-portrait.png`, запустіть `npm run images:optimize` і вкажіть у `image` отриманий `<id>-portrait.webp`. Коміт включає й отриманий WebP.
4. `accent` може бути `cyan`, `purple` або `lime`.
5. `profileSections` визначає назви й запитання семи розділів. `content` містить решту тексту презентації.
6. Тексти огляду зберігаються в `content.overview` та `content.dev.team`. `teamSize = 11` задає загальну кількість місць. Порожні місця обчислюються автоматично й зникають у міру додавання реальних профілів; вони не створюють порожніх слайдів.
7. У `technologies` вкажіть основні технології учасника. Якщо на картці огляду потрібно показати конкретні дві, додайте `cardTechnologies` з назвами, які вже є у `technologies`.
8. `helpOthers` — відповідь на «Чим можете бути корисними іншим студентам».

Відповіді розраховані на 1–3 короткі речення. Для проєктора довші тексти учасників скорочено зі збереженням змісту й особистого тону. Фото надані учасниками. Повні надані відповіді Валентини Дрозд і Олени Гокун збережені в `docs/member-submissions-2026-10-02.json`, Тетяни — у `docs/member-submissions-2026-10-04.json`, Бориса — у `docs/member-submissions-2026-10-05.json`, Владислава — у `docs/member-submissions-2026-10-06.json`; слайди використовують коротші версії з `src/data/team.ts`. Портрети з прозорим фоном зберігаються в `public/photos/`. Інструкції редагування через вбудований `image_gen` записані в `docs/team-portrait-prompts.txt`. Професійні факти Андрія — з наданого CV; мотивація, навчальна ціль та плани після магістратури — чернетка на основі обговорення.

## Перевірка

```sh
npx playwright install chromium
npm test
npm run build
```

Playwright запускає окремий сервер на 4287: зупиніть dev-сервер перед `npm test`. Перевірки охоплюють повний шлях від вступу до фіналу, вибір учасника, клавіатуру, активацію Space та адаптивність. Production build перевіряє TypeScript у strict-режимі.

## Дизайн

Презентація має 12 слайдів для дев’яти учасників: вступ, команда, один слайд на учасника та один інтерактивний підсумок. Для 11 людей буде 14 слайдів — формат для короткого живого представлення команди за 10 хвилин. Великі заголовки й стримані світлові акценти формують презентаційний стиль. Усі сім відповідей кожного учасника відображаються одночасно, поки він розповідає про себе голосом. Фото та аватари мають вертикальну пропорцію 3:4 із портретним кадруванням.

На старті збирається об’ємний модуль TEAM_OS: три шари з перспективою, світловими гранями та тінями. Заставка триває 4 секунди й показує плавний прогрес та чотири етапи. Почати можна одразу кнопкою або клавішею. Це декоративний запуск; reduced motion пропускає заставку та вимикає переходи й миготіння.

Оновлений вступ: loader показується лише перед головним слайдом; повторного блоку ініціалізації немає. На вступі є одна кнопка «Познайомитися». Нижнє меню розділів прибрано; після вступу навігація відбувається кнопками «Назад / Далі» або клавіатурою.

Палітра натхненна [Neoversity](https://neoversity.com.ua/): фіолетові та блакитні градієнти на темному індиго. На вступі `TechnologyOrbit` показує до 12 унікальних технологій: `selectTeamTechnologies` відбирає впізнавані назви з реальних профілів за каталогом `featuredTechnologyNames` у `team.ts`. Серед відповідних технологій бере перші дві кожного учасника по черзі, а вільні місця заповнює найпоширенішими. Після редагування `team` бейджі оновлюються автоматично. Каталог можна доповнити новою технологією; назва з’явиться лише за наявності в профілі. На десктопі об’ємні бейджі розміщені навколо багатошарового AI-блоку з перспективою й легко реагують на курсор; на телефоні переходять у три колонки. Налаштування зменшеного руху вимикає паралакс і фонову анімацію, зокрема при зміні налаштування під час показу.

На широких екранах (від 1880 × 800) `SideNotes` заповнює бокові поля поза основним слайдом. Ліворуч — команда для поточного розділу або учасника, праворуч — кодовий цикл навчання та кнопка `npm run idea`, що перемикає короткі фрази. На ноутбуках шириною 1280–1879 px показуються компактні вертикальні підписи; на планшеті й телефоні нотатки приховані. Команди є візуальними метафорами й не виконуються. Усі тексти зберігаються в `content.sideNotes`. Зменшений рух вимикає їхню анімацію.

## Інтерактивні профілі

Профіль зберігає всі сім відповідей на одному слайді. Кожен блок можна натиснути або відкрити через Tab + Enter/Space: відповідь з’явиться у великому вікні з плавним переходом. Стрілки перемикають розділи поточного учасника, Home/End відкривають перший/останній розділ, Esc закриває вікно та повертає фокус на початковий блок. Кнопки попереднього й наступного розділів доступні для миші та дотику. У відкритому вікні клавіші не перемикають слайди; після закриття звичайна навігація презентації відновлюється. Зменшений рух вимикає зміщення та анімацію появи. Довгі посади й наступні кроки в рядку професійного шляху переносяться повністю без обрізання.

Теми мають спільні іконки на слайді й у розгорнутій відповіді. Чотири блоки деталей використовують окремі кольори та легкі фонові символи. Кодові підписи на кшталт `learning.why()` і `team.support()` — декоративні метафори, що зберігаються у `profileSections` в `src/data/team.ts`. Вони показуються лише на просторих екранах; іконки адаптуються до компактного режиму. Reduced motion вимикає рух під час наведення.

## Публікація

Код зберігається у публічному репозиторії `andrii-koptiev/neo_group1_presentation`. Workflow `.github/workflows/deploy-pages.yml` збирає презентацію та публікує її через GitHub Pages після push у `main`. Сайт і вихідний код доступні без авторизації. Публічна презентація: https://andrii-koptiev.github.io/neo_group1_presentation/. Відносна база Vite дозволяє працювати під шляхом репозиторію. Для локальних фото використовуйте відносні шляхи `photos/name.jpg`.

Огляд показує 11 місць в одній сітці: дев’ять отриманих профілів і дві картки «скоро знайомство» однакової висоти. Великі картки займають весь доступний простір під заголовком. Якщо вони не вміщуються, прокручується лише список; шапка й навігація залишаються на місці. Прокручування працює колесом, дотиком і клавішами Page Up / Page Down після фокусу на списку. На десктопі — чотири колонки, на ноутбуці — три, на планшеті — дві, на телефоні — одна з фото збоку. На картках показуються лише імена; повні імена збережено в профілях і доступних назвах кнопок. Під посади зарезервовано однакові три рядки, тому портрети всіх учасників мають однакову висоту. Посади розміщено під іменами; цифри мають окремі бейджі. Два бейджі технологій відбираються з реальних даних учасника через `selectTeamTechnologies`: OutSystems та загальні поняття на кшталт Microservices залишаються в повному профілі. Наведення або фокус підсвічує картку та показує `git switch team/<id>` у підказці. Reduced motion вимикає рух карток. На екрані підсумку врахована повна кількість учасників без вигаданих профілів.
