# TEAM_OS — Neoversity

Інтерактивна презентація команди українською. React, TypeScript, Vite, Framer Motion, звичайний CSS. Без бекенду, авторизації та API. Шрифти постачаються локально з npm, тому після запуску інтернет для показу не потрібен.

## Запуск

```sh
npm install
npm run dev
```

Відкрийте **http://localhost:4287**. Порт 5173 не використовується. `strictPort` не дозволяє непомітно перейти на інший порт. Preview використовує 4288.

```sh
npm run build
npm run preview
```

## Керування

- `→` / `Space`: наступний слайд / учасник.
- `←`: попередній слайд.
- `Escape`: повернутися до команди з профілю.
- `Home` / `End`: вступ / фінал.
- Картка учасника відкриває його профіль. Усі сім відповідей видно одночасно; стрілки перемикають учасників.
- Кнопка у правому верхньому куті вмикає повноекранний режим, якщо браузер підтримує його.
- Space на кнопці використовує стандартну активацію кнопки без подвійного переходу.

## Заміна даних

У **src/data/team.ts**:

1. Замініть об’єкти масиву `team` на справжніх учасників. Кожен має унікальний `id` та всі поля `TeamMember`.
2. Додавайте 5–10 об’єктів без змін компонентів — порядок слайдів, кількість учасників і прогрес перебудовуються автоматично.
3. Додайте фото до `public/photos/` та вкажіть `image: 'photos/andrii.jpg'`, `imageAlt: 'Портрет Андрія'`. Без фото або якщо файл недоступний, відобразиться аватар-заглушка.
4. `accent` може бути `cyan`, `purple` або `lime`.
5. `profileSections` визначає назви й запитання семи розділів. `content` містить решту тексту презентації.
6. Після заміни демонстраційних профілів змініть `content.sample`, щоб прибрати позначку демонстраційних даних.

Відповіді розраховані на 1–3 короткі речення. Для проєктора короткий текст читабельніший. Усі нинішні профілі — демонстраційні приклади.

## Структура

```text
src/
  components/   # Оболонка, навігація, прогрес, аватар, картка, відповідь, code-accent
  screens/      # Вступ, команда, профіль, підсумок, фінал
  data/team.ts  # Дані учасників, запитання й тексти інтерфейсу
  hooks/usePresentationNavigation.ts # Послідовність слайдів та клавіатура
  App.tsx
  main.tsx
  styles.css
tests/presentation.spec.ts
```

## Перевірка

```sh
npx playwright install chromium
npm test
npm run build
```

Playwright запускає окремий сервер на 4287: зупиніть dev-сервер перед `npm test`. Перевірки охоплюють повний шлях від вступу до фіналу, вибір учасника, клавіатуру, активацію Space та адаптивність. Production build перевіряє TypeScript у strict-режимі.

## Дизайн

Презентація має 7 слайдів для трьох прикладів: вступ, команда, один слайд на учасника, підсумок та фінал. Для 10 людей буде 14 слайдів — формат для короткого живого представлення команди за 10 хвилин. Великі заголовки й стримані світлові акценти формують презентаційний стиль. Усі сім відповідей відображаються одночасно у двох колонках, поки учасник розповідає про себе голосом. JSON-об’єкт залишається невеликим акцентом під фото на великому екрані та приховується на мобільних пристроях. На старті показується проста декоративна заставка із сегментованим прогресом. Вона триває 4 секунди, але почати можна одразу кнопкою або клавішею. Це не очікування мережі; reduced motion пропускає заставку. Фото та аватари мають вертикальну пропорцію 3:4 із портретним кадруванням. Системна опція зменшення руху вимикає переходи та миготіння.

Оновлений вступ: loader показується лише перед головним слайдом; повторного блоку ініціалізації немає. На вступі є одна кнопка «Познайомитися». Нижнє меню розділів прибрано; після вступу навігація відбувається кнопками «Назад / Далі» або клавіатурою.

## Форматування

```sh
npm run format
npm run format:check
```

Prettier застосовує єдиний стиль до TypeScript, TSX, CSS, HTML, JSON та Markdown. Конфігурація: `.prettierrc.json`; базові відступи та переноси рядків для редакторів: `.editorconfig`.
